# EZ Dealer — Warranty Virtual Printer

Auto-update distribution repository for the **Warranty Virtual Printer** application.

## Latest Version

See [Releases](https://github.com/HARIOHMPATEL/ezdealer-warranty-virtual-printer/releases/latest) for the latest installer.

## Auto-Update

The app checks `version.json` on startup:

```
https://raw.githubusercontent.com/HARIOHMPATEL/ezdealer-warranty-virtual-printer/main/version.json
```

If a newer version is available, it downloads the installer from the latest GitHub Release.

## Install

Download the latest `WarrantyVirtualPrinterSetup.exe` from [Releases](https://github.com/HARIOHMPATEL/ezdealer-warranty-virtual-printer/releases).
